# Quy ước đọc âm: đề xuất gom từ báo cáo các agent soạn

*Điều phối gom ngày 16/11/2026. Đây là **đầu vào** cho agent review thống nhất cấp chữ (pha 5), **chưa phải quyết định cuối**.*

## A. Từ hard_01 (Opus)

1. **Chữ thanh nhẹ** lấy âm của chữ gốc: 气 khí, 西 tây, 生 sinh, 上 thượng, 识 thức, 夫 phu, 子 tử, 么 ma, 里 lý, 务 vụ, 量 lượng, 拾 thập, 处 xứ.
2. **不** luôn đọc "bất", kể cả khi biến điệu thành bú.
3. **过** mặc định đọc "quá" (quá khứ, quá trình). Đọc "qua" chỉ trong từ Việt quen âm đó: 经过 KINH QUA, 通过 THÔNG QUA.
4. **Chữ chỉ có một âm cố định:**

   | Chữ | Âm | Ghi chú |
   |---|---|---|
   | 正 | chính | không dùng "chánh" |
   | 从 | tòng | |
   | 主 | chủ | |
   | 当 dāng | đương | |
   | 担 | đảm | |
   | 使 | sử | 使馆 đọc "sứ" |
   | 住 | trú | |
   | 司 | ti | |
   | 否 | phủ | |
   | 合 hé | hợp | |
   | 刷 | loát | |
   | 句 | cú | |
   | 厅 | sảnh | |
   | 更 gēng | canh | |
   | 未 | vị | |

5. **行:** xíng đọc "hành", háng đọc "hàng".
6. **比** đọc "tỷ", không đọc "bỉ".
7. **思:** sī đọc "tư". Riêng 意思 và các từ cùng nhóm đọc Ý TỨ (khác dùng).
8. **Chọn theo nghĩa:**

   | Chữ / từ | Âm |
   |---|---|
   | 教 jiāo | giáo |
   | 容易 | dị |
   | 交易 | dịch |
   | 几乎 | CƠ HỒ |
   | 难 (khó) | nan |
   | 累 lěi | lũy |
   | 刺激 | THÍCH KÍCH |

9. **Khi Thiều Chửu không phân biệt được,** lấy theo hvpinyin: 你 nễ, 姐 tỷ, 挑 khiêu, 稍 sảo, 背 bēi bối, 卡 kǎ ca.
10. **Chọn phồn thể theo nghĩa:** 吃→喫, 后→後, 才→纔, 只→隻, 困→睏, 咸→鹹, 表→錶, 准→準, 冲→沖, 台→臺, 丑→醜, 获→穫, 念→唸, 签→簽, 云→雲.
11. **Âm của từ Việt không có trong danh sách ứng viên:** lấy ứng viên gần nhất, `tu_viet` vẫn ghi từ Việt thật (安慰: AN ỦY, từ Việt "an ủi").

**Điểm tranh cãi hard_01 nêu:**
- 妈妈 hard_01 giữ MÁ MÁ, nhưng Thiều Chửu ghi "ma". Cần chốt.
- 师傅: phó hay phụ? (Tiếng Việt quen nói "sư phụ", vốn là 師父.)
- 划 huá: hoạch hay hoa?

## A2. Từ hard_02 (Opus)

**Ưu tiên âm của từ Việt có sẵn:**
- 公主 CÔNG CHÚA, 主宰 CHÚA TỂ; các trường hợp khác 主 đọc "chủ".
- 服从 PHỤC TÙNG, 从容 THUNG DUNG; các trường hợp khác 从 đọc "tòng".
- 司令, 司法 đọc "tư"; 上司 đọc "ti".
- 词汇 TỪ VỰNG (彙). Hv_pre ghi TỪ HỐI là sai. 汇 với nghĩa chuyển tiền (匯) đọc "hối".
- 答复 ĐÁP PHÚC.

**Chọn âm theo nghĩa:**

| Chữ | Âm |
|---|---|
| 营 | doanh (kinh doanh); dinh (dinh dưỡng) |
| 断 | đoạn (đứt); 诊断 đoán |
| 两 | lưỡng |
| 角 | giác |
| 访 | phỏng |
| 率 shuài | suất |
| 载 | tải |
| 使 | sử (sai khiến); sứ (sứ giả, đại sứ) |
| 过 | qua khi nghĩa là "đi qua" (穿过, 透过) |
| 刺 | thích |
| 伺 | tứ |
| 泡 pào | bào |
| 歪 | oa |
| 仓促 | THẢNG XÚC |
| 呆 | ngốc |

**Chọn phồn thể theo nghĩa:**
- 并: nghĩa gộp → 併, đọc "tính"; nghĩa "và" → 並, đọc "tịnh".
- 松 (lỏng) → 鬆, đọc "tông".
- 折 (gấp) → 摺, đọc "triệp".
- 台风 → 颱.

## B. Từ các lô Sonnet

**Không thống nhất giữa các lô, phải chốt:**
- 受: thọ hay thụ? (01b, 02b, 04a đổi sang THỤ; vẫn còn chỗ THỌ trong 受不了, 受伤.)
- 单: đan hay đơn? (Điều phối đã chốt ĐƠN; các lô đầu như 床单 vẫn còn ĐAN.)
- 推: suy hay thôi? (04a dùng THÔI cho 推动, 推广, 推进; giữ SUY cho 推荐.)
- 当作, 当成: đáng hay đương?
- 尽: tận hay tẫn? (02b dùng TẪN cho 尽管; 04a giữ TẬN cho 尽快, 尽量.)
- 调: điều hay điệu? (Đã chốt: tiáo đọc ĐIỀU.)
- 要: yếu hay yêu? (Đã chốt theo pinyin.)
- 轻松: tông hay tùng?
- 安静: AN TĨNH hay YÊN TĨNH? (01b đổi sang YÊN.)

**Âm có trong nguồn nhưng đáng ngờ:**
- 喝 húp, 找 trảo/hoa, 抬 đài, 崭 tiệm/sàm.
- 方便面 bị ghi "MÌ": âm ngoài nguồn và sai số âm. Phải sửa.

**Từ Việt dùng âm không có trong nguồn:** 资源 tài nguyên, 身份 thân phận, 安慰 an ủi.
